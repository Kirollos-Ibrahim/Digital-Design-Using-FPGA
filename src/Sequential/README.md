# Sequential Design

This directory contains Verilog HDL implementations of sequential logic circuits. Unlike combinational logic, these designs depend on both the current input values and previously stored states through clocked storage elements.

The projects in this directory demonstrate the core components used in synchronous digital systems and FPGA-based designs.

---

## Design Categories

Examples of circuits included in this directory:

* Flip-Flops
* Registers
* Shift Registers
* Counters
* Finite State Machines (FSMs)

Additional sequential designs will be added as the repository expands.

---

## Verification

Each design is accompanied by dedicated testbenches for functional verification using **ModelSim**, followed by synthesis and RTL analysis using **Xilinx Vivado** where applicable.
