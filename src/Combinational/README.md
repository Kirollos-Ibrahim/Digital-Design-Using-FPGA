# Combinational Design

This directory contains Verilog HDL implementations of combinational logic circuits. These designs produce outputs based solely on the current input values and do not require clock signals or memory elements.

The projects in this directory focus on the fundamental building blocks of digital systems and serve as the foundation for more advanced hardware designs.

---

## Design Categories

Examples of circuits included in this directory:

* Multiplexers (MUXs)
* Decoders
* Encoders
* Code Converters

Additional combinational designs will be added as the repository continues to grow.

---

## Implementation

Whenever applicable, each circuit is implemented using multiple Verilog modeling styles:

* Gate-Level Modeling
* Dataflow Modeling
* Behavioral Modeling

This approach highlights different RTL design techniques while maintaining equivalent hardware functionality.

---

## Verification

Each design is intended to be verified using dedicated Verilog testbenches through **ModelSim**, with synthesis performed using **Xilinx Vivado** for applicable projects.
