# Vivado

This directory contains the **Xilinx Vivado** projects and synthesis files generated for the digital design modules in this repository. These projects are used to analyze, synthesize, and prepare the Verilog HDL designs for FPGA implementation.

The synthesis results provide insight into the generated hardware structure and resource utilization of each design.

---

## Contents

This directory may include:

* Vivado project files
* RTL schematics
* Synthesis reports
* Constraint files (XDC)
* Implementation outputs
* Generated project files

---

## Synthesis

The Vivado projects are used to:

* Synthesize Verilog HDL designs
* Generate RTL schematics
* Analyze synthesized hardware
* Verify design readiness for FPGA implementation

---

## Notes

The synthesis projects are created from the verified RTL designs in the `src` directory after successful functional verification using **ModelSim**, following a standard FPGA development workflow.
