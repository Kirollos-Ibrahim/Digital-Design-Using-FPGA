# ModelSim

This directory contains the **ModelSim** projects and simulation files used for the functional verification of the Verilog HDL designs in this repository. Simulation is performed to validate the behavior of each design before synthesis and hardware implementation.

The generated waveforms and simulation outputs provide visual confirmation that the implemented logic operates according to its specifications.

---

## Contents

This directory may include:

* ModelSim project files
* Simulation scripts
* Waveform configuration files
* Simulation outputs
* Supporting verification files

---

## Verification

The simulations are used to verify:

* Functional correctness
* Input and output behavior
* Clock and reset operation (for sequential designs)
* Design behavior under different test scenarios

---

## Notes

The simulation files in this directory correspond to the Verilog modules in the `src` directory and their associated testbenches in the `testbenches` directory, providing a complete functional verification workflow.
