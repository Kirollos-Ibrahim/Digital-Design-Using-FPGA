# HDLBits

This directory contains my solutions to **HDLBits** Verilog HDL exercises, covering a wide range of digital design concepts from basic combinational circuits to advanced sequential logic and finite state machines.

The purpose of this collection is to strengthen RTL design skills, reinforce Verilog HDL concepts, and document my progress while solving industry-relevant hardware design problems.

---

## Objectives

* Practice Verilog HDL through structured exercises
* Improve RTL design and coding skills
* Strengthen problem-solving techniques
* Build a reference library of Verilog implementations
* Prepare for FPGA, RTL Design, and Verification engineering roles

---

## Solution Format

Each solved problem includes:

* Verilog HDL source code
* Link to the original HDLBits problem
* Clear and readable RTL implementation
* Photo of the results and waveforms

Solutions are organized according to the HDLBits problem categories whenever applicable.
